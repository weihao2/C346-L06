# Video Game Logo Quiz

A simple React Native quiz app where users identify game logos and view their score upon submission.

# Features Highlight

* **Image Questions:** Displays game logos using `Image` within a `ScrollView`.
* **Dropdown Selection:** Uses `@react-native-picker/picker` for multiple-choice answers.
* **State Tracking:** Tracks selections using React `useState`.
* **Score Alerts:** Calculates the total score and shows custom feedback alerts.
